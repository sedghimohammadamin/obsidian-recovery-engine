# Recovery Engine

An intelligent review management system for Obsidian. Schedule, track, and review your study materials with fully customizable cycles.

## Features

- Add study items with Persian (Jalali) date support
- Flexible scheduling: initial cycle, weekend reviews, monthly aggregation, long-term reviews
- Dashboard showing today's, overdue, and upcoming reviews
- Per-subject checklists
- Monthly calendar view
- Chart-based reports
- JSON backup and restore
- macOS native notifications with action buttons (requires `alerter`)

## Installation

From Obsidian: Settings → Community Plugins → Browse → Recovery Engine

Or manually:

1. Copy `main.js`, `manifest.json`, `styles.css` into `.obsidian/plugins/recovery-engine/`
2. Reload Obsidian and enable the plugin from settings.

## Optional prerequisite (macOS)

For native notifications with buttons:

    brew install vjeantet/tap/alerter

## Development

    npm install
    npm run dev
    npm run build
